# RockCommerce Docs

## Features

- Fully translated to german

## Requirements & Considerations

- RockCommerce uses AlpineJS (v3) on the frontend, so you need to include it in your project.
- RockCommerce supports different currencies, but you have to decide which one to use globally.
- RockCommerce only supports currencies with two digits after the decimal. If you need to support other currencies get in touch!

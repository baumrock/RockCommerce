# RockCommerce E-Commerce/Shop Module for ProcessWire

RockCommerce is a lightweight, flexible e-commerce solution for ProcessWire that puts you in control. Unlike traditional e-commerce platforms that force you into specific workflows, RockCommerce provides the essential building blocks while letting you define how products, carts, and checkouts work in your store.

## Key Features

- 🛍️ Product management through ProcessWire pages
- 🛠️ Product variations
- 💰 Order management
- 🔌 Easy integration with payment providers (like Mollie, for example)
- ⚡ Frontend-driven cart system using Alpine.js
- 🎨 Fully customizable markup, styling
- ⚓ Extensible through ProcessWire hooks
- 🚀 Full ProCache support

Perfect for developers who want to build custom e-commerce solutions without the overhead of complex platforms, while leveraging ProcessWire's powerful content management capabilities.
